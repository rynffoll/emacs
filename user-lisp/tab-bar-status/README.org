#+title: tab-bar-status
#+author: Ruslan Kamashev

The status of buffers on their tab-bar tabs, e.g. an agent in a terminal
that is working, blocked on a prompt or done.

The package keeps no status.  Backends in =tab-bar-status-functions=
report the status of a buffer; after each =tab-bar-status-update= the
next display asks them anew, once for all tabs, and shows the status on
the tabs =tab-bar-status-tab-predicate= matches, the buffer's project
tab by default.  The only statuses kept here are marks, set on a tab by
hand, e.g. the flag =⚑=.

| Term      | Meaning                                       |
|-----------+-----------------------------------------------|
| status    | =blocked=, =error=, =done=, =working=, =flag= |
| indicator | a status's symbol with a face, =●= or =⚑=     |
| message   | text from the backend, =permission: Bash?=    |
| mark      | a status set on a tab by hand                 |

* Files

| File                               | Contents                                 |
|------------------------------------+------------------------------------------|
| =tab-bar-status.el=                | Display of statuses, marks               |
| =tab-bar-status-system-taskbar.el= | Badge and progress in the system taskbar |

The ghostel backend is =tab-bar-ghostel=.

* Layout

#+begin_example
 tab bar:
 1 *scratch*  2 emacs ●  3 *Proced* ⚑  4 dotfiles ●¹ ●¹        ●² ●¹ ⚑¹
                      │             │             │            └──┬───┘
                      │             │             │               └ summary: tabs per status
                      │             │             └ counts of a folded group, one per status;
                      │             │               the same ● differ by face: warning, success
                      │             └ flag, a mark
                      └ indicator after the name

 messages, e.g. in a tree of tabs:
 2 emacs ●
   permission: Bash?         ← the message
#+end_example

| Element        | Drawn by                                                   |
|----------------+------------------------------------------------------------|
| indicator      | =tab-bar-status-tab-name-format=, a tab name formatter     |
| group count    | =tab-bar-status-tab-group-format=, a group label formatter |
| summary        | =tab-bar-status-summary=, e.g. in =global-mode-string=     |
| message        | =tab-bar-status-tab-messages=, e.g. in a tree of tabs      |
| system taskbar | =tab-bar-status-system-taskbar-mode=                       |

* Statuses

=tab-bar-status-alist=, =(STATUS STRING FACE)=; statuses, and the tabs
and messages that have them, are listed in its order:

| Status    | Indicator | Face      | Color |
|-----------+-----------+-----------+-------|
| =working= | ●         | =shadow=  | ⚪    |
| =blocked= | ●         | =warning= | 🟡    |
| =done=    | ●         | =success= | 🟢    |
| =error=   | ●         | =error=   | 🔴    |
| =flag=    | ⚑         | =shadow=  | 🚩    |

/Color/ shows the face as an emoji, for viewers without faces such as
GitHub; the same emoji are the default taskbar badge strings, see
[[*System taskbar][System taskbar]].

The =working= indicator blinks after a tab name and in the summary, see
=tab-bar-status-blink-statuses=: =blinker= dims it to the color of
=blinker-blend= every =blinker-interval= seconds; its count does not
blink.

A status lives as long as its backend reports it: a terminal's =done=
goes when ghostel drops the record.  A mark lives on its tab until
toggled off.

* Backends

A backend is a function of a buffer that returns nil or a plist:

#+begin_src emacs-lisp
(defun my-status (buffer)
  (when (buffer-local-value 'my-failed buffer)
    '(:status error :message "build failed")))

(add-hook 'tab-bar-status-functions #'my-status)
;; and on each change:
(tab-bar-status-update)
#+end_src

Backends run for every buffer after each =tab-bar-status-update=, so
they return early for buffers they do not handle.

* API

- =tab-bar-status-update= — redisplay and run =tab-bar-status-change-hook=
- =tab-bar-status-tab-messages= — the messages of a tab, a value for
  =tab-bar-tree-tab-status-function=
- =tab-bar-status-summary= — counts of tabs per status, as a string
- =tab-bar-status-progresses= — the progress of every buffer reporting one
- =tab-bar-status-switch-to-tab= — go to a tab with a status, by default
  the one whose status comes first, and show its buffer
- =tab-bar-status-toggle= — toggle a mark on the current tab
- =tab-bar-status-tab-indicators= — indicators of a tab, e.g. for
  completion icons

* System taskbar

=tab-bar-status-system-taskbar-mode= needs =system-taskbar-mode=:

| Element  | Shows                                                                |
|----------+----------------------------------------------------------------------|
| badge    | summary of all tabs, per =tab-bar-status-system-taskbar-badge-alist= |
| progress | mean progress of all buffers                                         |

The badge has no faces, so it shows a colored string per status, ⚪ 🟡
🟢 🔴 🚩 by default, or the indicator string.  A blinking status
alternates with its string in
=tab-bar-status-system-taskbar-blink-alist=, ⚫ for =working=.

* Configuration

#+begin_src emacs-lisp
(use-package tab-bar-status
  :init
  (setq tab-bar-tree-tab-status-function #'tab-bar-status-tab-messages)
  :hook
  (tab-bar-status-change-hook . tab-bar-tree-update)
  (tab-bar-status-blink-hook . my-blink-tree)
  :config
  ;; Shown on the tab bar by `tab-bar-format-global'.
  (add-to-list 'global-mode-string
               '(:eval (tab-bar-status-summary (funcall tab-bar-tabs-function))))
  ;; Blink in tree buffers without redrawing them; the summary in the
  ;; header line blinks too.
  (defun my-blink-tree ()
    (mapc #'blinker-update-buffer
          (match-buffers '(derived-mode . tab-bar-tree-buffer-mode)))
    (tab-bar-tree-update-header-line)))

(setq tab-bar-tab-name-format-functions
      '(tab-bar-tab-name-format-truncated
        tab-bar-status-tab-name-format
        tab-bar-tab-name-format-hints
        tab-bar-tab-name-format-close-button
        tab-bar-tab-name-format-face))

(use-package tab-bar-status-system-taskbar
  :hook
  (after-init-hook . tab-bar-status-system-taskbar-mode))
#+end_src

| Option                          | Meaning                                                                            |
|---------------------------------+------------------------------------------------------------------------------------|
| =tab-bar-status-functions=      | backends: buffer → status report                                                   |
| =tab-bar-status-tab-predicate=  | tab and buffer directory → status shows on tab                                     |
| =tab-bar-status-alist=          | statuses: indicator string and face, order                                         |
| =tab-bar-status-change-hook=    | run by =tab-bar-status-update=                                                     |
| =tab-bar-status-blink-statuses= | statuses whose indicator blinks on a tab and in the summary                        |
| =tab-bar-status-blink-hook=     | run on each blink; call =blinker-update-buffer= on buffers showing tab names       |
