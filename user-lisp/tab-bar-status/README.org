#+title: tab-bar-status
#+author: Ruslan Kamashev

The status of tab-bar tabs, in two forms:

- the *current status*, reported by a source such as a program in a
  terminal: a state, e.g. =working=, =blocked= or =done=, a line of
  text and a progress, shown as status lines under the tab while the
  source runs;
- *indicators*, colored symbols after the tab name that keep a status
  until the tab is viewed: a source entering =blocked=, =error= or
  =done= sets indicators on its tabs, and =⚑= is a flag set by hand.

States follow the [[https://www.superlogical.com/rex/docs/build/program-status][terminal program status protocol]], OSC 7501; more
states can be added to =tab-bar-status-state-alist=.

* Layout

#+begin_example
 tab bar:
 1 *scratch*  2 emacs ●  3 *Proced* ⚑  4 dotfiles ●¹ ●¹        ●² ●¹ ⚑¹
                      │             │             │            └──┬───┘
                      │             │             │               └ summary
                      │             │             └ counts of a folded group, one per indicator type;
                      │             │               the same ● differ by face: warning, success
                      │             └ flag, set by hand, permanent
                      └ indicator after the name

 status lines, e.g. in a tree of tabs:
 2 emacs ●
   blocked: permission       ← the current status
#+end_example

| Element        | Drawn by                                                   |
|----------------+------------------------------------------------------------|
| tab indicator  | =tab-bar-status-tab-name-format=, a tab name formatter     |
| group count    | =tab-bar-status-tab-group-format=, a group label formatter |
| summary        | =tab-bar-status-summary=, e.g. in =global-mode-string=     |
| status lines   | =tab-bar-status-tab-lines=, e.g. in a tree of tabs         |
| system taskbar | =tab-bar-status-system-taskbar-mode=, see [[*System taskbar][System taskbar]]   |

* States

A program in a terminal reports its status with OSC 7501: a =state=, a
=msg= and, for =blocked=, a =kind= such as =permission=.  A terminal
source passes the state, the message or else the kind as the text, and
the progress:

#+begin_example
 source         current status    shown as
 ───────────    ──────────────    ───────────────────────────────────────
 a terminal ──► working, text ──► status line   working: Reading files
            ──► working, 42   ──► status line   working: 42%
            ──► working       ──► status line   working: ․ ‥ … (spinner)
            ──► blocked, kind ──► status line   blocked: permission
                                  indicator     :warning, until viewed
            ──► error, text   ──► status line   error: Exit 1
                                  indicator     :error, until viewed
            ──► done          ──► indicator     :success, until viewed
            ──► idle          ──► nothing
#+end_example

The current status lives as long as its source: a buffer's status goes
with the buffer.  An indicator lives on the tab until the tab is viewed,
and is saved with it.  So a =blocked= agent keeps its status line after
you view the tab, and a =done= agent leaves only its indicator.

A status line is =STATE: TEXT=.  If the text is missing, the line
shows the progress instead, e.g. =42%=, or a spinner if there is no
progress.  =tab-bar-status-state-alist= gives each state what it
shows: =:indicator=, the type set on the tabs entering it, and =:line t=
for a status line.

* Indicators

A tab can carry several indicators, one per type in
=tab-bar-status-indicator-alist=:

| Type       | Symbol | Face      | Permanent |
|------------+--------+-----------+-----------|
| =:warning= | ●      | =warning= |           |
| =:error=   | ●      | =error=   |           |
| =:success= | ●      | =success= |           |
| =:flag=    | ⚑      | =shadow=  | yes       |

Indicators are stored as a tab parameter and disappear with the tab.  A
non-permanent indicator is removed when its tab comes into view (the
selected tab of a focused frame), and is not set on a tab in view.

* API

- =tab-bar-status-set= — set the current status of a source, e.g. a
  terminal buffer, with a predicate on tabs and an optional progress
- =tab-bar-status-remove= — remove the current status of a source
- =tab-bar-status-tab-lines= — the status lines of a tab, a value for
  =tab-bar-tree-tab-status-function=
- =tab-bar-status-set-indicator-if=,
  =tab-bar-status-remove-indicator-if= — set or remove an indicator on
  the tabs matching a predicate
- =tab-bar-status-set-state-indicator= — set indicators on the tabs of a
  predicate per a state, for events that set no current status
- =tab-bar-status-toggle-indicator= — toggle an indicator on the
  current tab
- =tab-bar-status-switch-to-indicated-tab= — switch to a tab with an indicator
- =tab-bar-status-indicators=, =tab-bar-status-indicated-tabs=,
  =tab-bar-status-indicated-group-tabs= — indicators and indicated tabs
- =tab-bar-status-summary= — indicator counts as a string
- =tab-bar-status-change-hook= — run when indicators or statuses change,
  including spinner frames; add =tab-bar-tree-update= to it

#+begin_src emacs-lisp
(tab-bar-status-set (current-buffer)
                    (lambda (tab) (equal (alist-get 'name tab) "emacs"))
                    'working "Reading files")
#+end_src

* System taskbar

=tab-bar-status-system-taskbar-mode= shows the status of tabs in the
system taskbar; it needs =system-taskbar-mode=:

| Element   | Shows                                                                   |
|-----------+-------------------------------------------------------------------------|
| badge     | indicators of all tabs, per =tab-bar-status-system-taskbar-badge-alist= |
| progress  | mean progress of all sources                                            |
| attention | on a new indicator, per =tab-bar-status-system-taskbar-attention-alist= |

The badge has no faces, so it shows a colored string per indicator
type, 🟡 🔴 🟢 🚩 by default, or the type's =:symbol= if it has none.

* Configuration

=tab-bar-status-mode= sets indicators on state changes and removes them
on view; status lines do not depend on it.  To display indicators, add
=tab-bar-status-tab-name-format= to =tab-bar-tab-name-format-functions=
after =tab-bar-tab-name-format-truncated=:

#+begin_src emacs-lisp
(use-package tab-bar-status
  :init
  (setq tab-bar-tree-tab-status-function #'tab-bar-status-tab-lines)
  :hook
  (after-init-hook . tab-bar-status-mode)
  (tab-bar-status-change-hook . tab-bar-tree-update)
  :config
  ;; Indicator counts, shown on the tab bar by `tab-bar-format-global'.
  (add-to-list 'global-mode-string
               '(:eval (tab-bar-status-summary
                        (tab-bar-status-indicated-tabs)))))

(setq tab-bar-tab-name-format-functions
      '(tab-bar-tab-name-format-truncated
        tab-bar-status-tab-name-format
        tab-bar-tab-name-format-hints
        tab-bar-tab-name-format-close-button
        tab-bar-tab-name-format-face))

(use-package tab-bar-status-system-taskbar
  :hook
  (after-init-hook . tab-bar-status-system-taskbar-mode))
#+end_src
