#+title: tab-bar-ghostel
#+author: Ruslan Kamashev

Terminal status on tab-bar tabs: a =tab-bar-status= backend for ghostel.

A program in a ghostel terminal can report its state with OSC 7501, e.g.
an agent working, blocked on a prompt or done.  Ghostel keeps the
records in =ghostel-program-status=; =tab-bar-ghostel-status= returns
the terminal's most urgent record as its status, and
=tab-bar-status= shows it on the terminal's tab.

* Layout

#+begin_example
 OSC 7501 ──► ghostel-program-status ◄── tab-bar-ghostel-status ◄── tab-bar-status, after each update
              records                     most urgent record:
                  │                       status, message, progress
                  └─ change ──► tab-bar-ghostel--status-change ──► tab-bar-status-update
#+end_example

The message is the record's =msg=, else its =title=, after the =kind= of a =blocked= record or the progress of a =working=
one, e.g. =permission: Bash?= or =42% Build=; a =done= record
has none.

Ghostel drops records by itself: =done= and =error= per
=ghostel-status-auto-acknowledge=, =working= and =blocked= at the next
prompt or process exit, all of them with the buffer.

* Configuration

#+begin_src emacs-lisp
(use-package tab-bar-ghostel
  :hook
  (after-init-hook . tab-bar-ghostel-mode))
#+end_src

| Option                     | Meaning                                  |
|----------------------------+------------------------------------------|
| =tab-bar-ghostel-statuses= | record statuses shown, most urgent first |

The tab of a terminal is set by =tab-bar-status-tab-predicate=.
